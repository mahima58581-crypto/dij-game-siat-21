## 📖 معرفی

**دیجی گیم** یک وب‌اپلیکیشن فارسی و راست‌چین (RTL) است که برای مدیریت کامل گیم‌نت‌ها و کلوپ‌های بازی VIP طراحی شده است. این سامانه هم یک **پنل مدیریتی جامع** برای صاحبان گیم‌نت و هم یک **وب‌سایت معرفی و فروش** با محاسبه‌گر سود، تعرفه‌ها، شبکه نصاب‌ها و مرکز دانلود ارائه می‌دهد.

### 🎯 برای چه کسانی مناسب است؟

- صاحبان گیم‌نت، کافه‌گیم و کلوپ‌های VIP
- مدیران ایستگاه‌های بازی PS5 / PC / XBOX / VR
- کسب‌وکارهایی که می‌خواهند هزینه‌ها، درآمد و نیروی انسانی خود را هوشمند کنند

## 🚀 راه‌اندازی سریع

### پیش‌نیازها

- [Node.js](https://nodejs.org/) نسخه ۱۸ یا بالاتر
- npm

### مراحل نصب

```bash
# ۱. دریافت مخزن
git clone https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
cd <REPO_NAME>

# ۲. نصب وابستگی‌ها
npm install

# ۳. ساخت فایل تنظیمات محیطی
cp .env.example .env.local
# سپس کلید API خود را در فایل .env.local قرار دهید

# ۴. اجرای برنامه در حالت توسعه
npm run dev
```

اکنون برنامه روی [http://localhost:3000](http://localhost:3000) در دسترس است.

## ⚙️ متغیرهای محیطی

فایل [`.env.example`](.env.example) را کپی کرده و مقادیر زیر را تنظیم کنید:

| متغیر | توضیحات | ضروری |
| --- | --- | --- |
| `GEMINI_API_KEY` | کلید API سرویس Gemini گوگل برای قابلیت‌های هوش مصنوعی | ✅ بله |
| `APP_URL` | آدرس میزبانی برنامه (برای لینک‌های خودارجاعی و API) | ✅ بله |

> ⚠️ فایل `.env.local` در `.gitignore` قرار دارد و هرگز به مخزن اضافه نمی‌شود. کلیدهای خود را عمومی نکنید.

## 🌐 English

**Digi Game** is a modern, fully-featured **game café & VIP club management system** built for PlayStation lounges, PC gaming cafés, and VR clubs. It ships both a **complete management panel** and a **public marketing website**.

### Key Features

- **Real-time station management** for PS5, PC, XBOX and VR stations (active / idle / reserved)
- **Smart time & power control** — session timers, automatic billing per hourly rate, remote power control
- **Buffet ordering** linked to each station and customer invoice
- **Customer loyalty club** with tiers (Bronze / Silver / Gold / Fakher), XP points, wallet balance and discounts
- **Online reservations**, **staff attendance & payroll** (overtime, delays, shifts)
- **ROI calculator**, pricing plans, partner-club directory, certified-installer network, blog, tutorials and download center
- **Dark / light mode**, audio alerts, Persian **RTL** UI (Vazirmatn font), fully responsive

### Tech Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Motion · Lucide React · Google Gemini

### Getting Started

```bash
git clone https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
cd <REPO_NAME>
npm install
cp .env.example .env.local   # add your GEMINI_API_KEY
npm run dev                  # → http://localhost:3000
```

See the [project structure](#-ساختار-پروژه) and [environment variables](#️-متغیرهای-محیطی) sections above for details.
